# BB Chat skeleton

Provide a self-contained browser chat client that can be launched locally, while documenting its direct-to-provider behavior and the local-storage risk of retaining API keys and conversation history.

## Acceptance criteria

1. The README documents browser and local static-server startup instructions.
2. The README warns that API keys and conversations are stored in browser local storage and must not be committed or shared.
3. The existing single-file client remains free of repository credentials and can be inspected or run without a build step.
